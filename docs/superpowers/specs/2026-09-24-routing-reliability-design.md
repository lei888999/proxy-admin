# 分流、防泄露与线路可靠性

用户确认：国内直连允许国内网站看到本机公网 IP。其他目的地及其 DNS 走代理；失败时不回退直连。保留用户显式选择 VPS 作为出口的能力。

实施范围：
- Mihomo 完整订阅：国内直连、未知域名代理 DNS、TUN 严格路由、IPv6 阻断、自动选择/故障切换（不包含 DIRECT）。无入站返回明确错误。
- sing-box 远程规则缓存落在持久化目录，首次仍需成功下载；离线重启使用缓存。按用户显式解析目标，避免默认 local resolver 绕过上游 DNS。
- 被引用出站禁止删除，管理员必须先改派用户，避免删除后悄悄回落直连。上游组必须显式选成员，避免跨用户混用出口。
- 协议 schema 驱动表单和后端验证；网络能力支持 TCP/UDP 集合，端口按交集冲突。
- 线路探测区分 VPS 到上游与客户端到 VPS，返回 TCP 延迟和失败样本。健康探测不代表图片上传或 UDP 一定可用。
- 参数按协议开放，不自动开启所有复用/拥塞算法。故障切换不保证现有连接无损迁移。

验证：Go/前端逻辑测试，固定版本 sing-box 与 Mihomo 配置检查，静态构建；真实晚高峰、客户端 TUN/系统断网保护及 WebRTC 在部署后按诊断文档验收。

边界：订阅不能启动操作系统级 kill switch；关闭客户端、未授权 TUN、应用排除、浏览器自行配置的网络路径需客户端实测。不能把 DNS 禁止 AAAA 解释为操作系统禁用 IPv6。AnyTLS 入站需要 sing-box 1.12.0 或更高版本。


## 2026-09-29：分流统一交给客户端

用户要求移除服务端的目的地分流和中国大陆规则。服务端只保留 auth_user → 绑定出口，以及必要的 DNS 出口绑定；无绑定时使用 VPS 出口。移除远程中国规则集、私网例外、Gemini 例外和管理员目的地规则。升级首次启动重新生成服务端配置一次，失败不标记完成。

自定义规则持久化结构为 type/value/policy/noResolve，可携带 RULE-SET 的 provider（URL/behavior/format）。按管理员顺序生成 Mihomo rules，类型和参数由服务端严格校验，策略只引用订阅实际存在的内置代理组或 DIRECT/REJECT。服务器上游标签不能作为客户端策略；旧规则按既有客户端语义迁移（direct → DIRECT，其余 → 节点）。保存只影响后续订阅响应，无需重启服务端。

客户端服务器地址直连和 IPv6 阻断优先于自定义规则；之后保留 Gemini、私网、中国大陆直连和默认代理兜底。MATCH 只替换最终兜底，不能吞掉前面的默认规则。规则集由客户端经代理下载，不由面板或 VPS 下载。自定义 DIRECT 是管理员主动放行本机直连。

验证：测试服务端无目的地规则/地理集、用户出口及 DNS 绑定不变、保存不调用 config writer、旧规则迁移、规则校验和顺序、单节点代理组引用、provider 生成、界面排序/保存/错误提示；运行完整测试、静态构建和真实内核配置校验。
